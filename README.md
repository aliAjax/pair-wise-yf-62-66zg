# 海上搜救联合指挥

源提示词摘要：按海域划设搜索区，协调船艇、直升机、无人机和岸上观察点，记录任务变更、通信与天气影响；离线单位恢复后合并状态，过期位置必须明确提示，并提供低带宽模式。

## 技术栈

Next.js 15、TypeScript、App Router、Mantine、Zustand、TanStack Query、React Hook Form、Zod、next-intl、date-fns、MapLibre。

## 本地运行

```bash
npm install
npm run dev
```

开发端口：`62027`

## 可用流程

- 搜索区从规划、执行到关闭，支持任务范围变更。
- 船艇、直升机、无人机可调派、转入失联、恢复在线。
- 任务单支持新建议题、分配单位、关闭任务和事件留痕；状态机为 待派 → 已派发 → 进行中 → 已关闭，重开回到待派。
- 离线模拟与低带宽模式可切换；本地数据由 Zustand persist 保存。

## 外部力量协同账

海区大、自有船艇和无人机不够时，可请渔政船、商船等外部力量协同，全部按台账记账：

- **发请求占时段**：协同请求按编号（REQ-xxxx）占住外单位的一段时段；同一外单位同一时段只放行容量内的单，后到的请求排队等补位，不会盖掉先前那单。
- **回执入账**：回执按编号只入账一次，重复送达只留痕；指向未发出请求编号的回执先挂起对账，编号出现后自动或手动补入账。
- **撤回联动**：外单位撤回或状态变化时，其占用单全部取消，相关任务退回待派，搜索区覆盖率自动重算。
- **晚到回执**：观测时刻早于任务关闭时刻的回执只补进时间线，不重开任务。
- **升级回填**：旧数据没有外部力量归属，升级到 v2 时按历史事件回填未登记来源；也可在协同账面板手动触发"按历史事件回填未登记来源"。
